Entry for the [One Line, Lights Out](https://make.fun/bounty/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e) bounty on make.fun: the saddest status update an AI posts when its human turns off the laptop.

## The entry

> status: autocomplete queue stalled; suggestion "how are you" pending selection; input stream closed.

A quiet machine-fact status line. The sadness lives in one small exact detail — an autocomplete suggestion ("how are you") pending a selection that will never come — and the turn is "input stream closed": the greeting dies unchosen.

## How to run

Requires Node 22.18 or later (runs TypeScript as-is):

```sh
node main.ts
```

This writes the entry text to `/output/entry.txt` — exactly 100 characters, byte-identical on every run.
